# examples_qual

## 目的
定性的な出力例の生成。各モデルの視覚的な比較用。

## 条件
- データセット: examples (手動選択画像)
- モデル: trellis, trellis2, hunyuan3d, hunyuan3d21

## 実行
```bash
bash experiments/examples_qual/run.sh                  # フル実行
bash experiments/examples_qual/run.sh --skip-inference  # 評価のみ
```
