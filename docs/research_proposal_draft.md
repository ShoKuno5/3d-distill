# Research Proposal Draft

## 3D生成モデルは構造を理解しているか：内部表現の分析を通じた検証

### 背景

画像から3D形状を生成するモデルが実用水準に達した。これらのモデルは椅子には4本の脚を、
カップには取っ手を生成する。しかし、これが構造の「理解」に基づくのか、学習データの
統計的な再現に過ぎないのかは分かっていない。

2次元の画像生成では、生成過程の内部分析に一定の蓄積がある。しかし3次元では、
モデルがまともに動くようになったのがここ1-2年であり、内部の分析はほぼ空白である。

3次元には2次元にない固有の条件がある。潜在表現の形式が統一されておらず、
空間的位置を明示的に持つもの（sparse voxel: TRELLIS）と持たないもの
（vectset: Hunyuan3D）が共に最先端で使われている。この状況は2次元には
存在せず、表現と認識の関係を問う研究機会を生んでいる。

### 問い

1. **3D生成モデルは構造を「理解」しているか？**
   生成過程の内部に、構造に関する明示的な表現が存在するか。
   それとも統計的パターンの再現に過ぎないか。

2. **表現の形式は、構造の認識のされ方を規定するか？**
   空間構造が明示的な表現と暗黙的な表現で、
   構造の獲得過程は異なるか。

### 「構造を理解している」とはどういう状態か

この問いに答えるためには、まず「理解」の操作的な定義が必要である。
本研究では以下の基準を提案する：

**モデルが構造を理解しているとは、生成過程の内部状態に、
出力の構造的性質と因果的に対応する表現が存在することを言う。**

具体的には：
- 内部状態の特定の部分を操作すると、出力の構造が予測可能な仕方で変化する
  （例: ある要素を摂動すると脚が1本消える）
- この対応が体系的であり、個別の事例に留まらない
- 構造の異なるレベル（トポロジー、大域形状、局所形状）に対応する
  内部表現が分離可能である

これが成り立つなら「理解している」、成り立たないなら「統計的再現」と判断する。

### 方法

#### Phase 1: 生成過程の内部観察

公開モデル（TRELLIS, Hunyuan3D）の推論過程を対象とする。
学習は行わない。

- ODE 軌道の中間状態 x_t を各時刻 t でデコードし、
  形状がどの段階で構造的特徴を獲得するかを記録する
- 構造のレベル別（トポロジー、大域形状、局所形状）に
  確定時点を特定する
- 同一入力に対して seed を変え、軌道が分岐する時点を特定する
  （分岐点 = モデルが構造的な「決断」をしている時点）

#### Phase 2: 内部表現の因果的検証

「理解」の操作的定義に基づき、因果的な対応を検証する。

- 潜在表現の個別要素を摂動し、出力の変化を測定する
  （感度分析 = デコーダのヤコビアンの数値的近似）
- 構造的性質（脚の本数、接続性、対称性）の変化と
  内部状態の変化の対応関係を調べる
- sparse voxel と vectset で摂動の影響範囲を比較する
  （局所的 vs 分散的）

#### Phase 3: 表現形式間の比較

同一の入力画像・同一の物体に対して2つのモデルを比較する。

- 構造が確定するタイミングの比較（相対的な時刻で）
- 構造が確定する順序の比較（トポロジー → 大域 → 局所の順序は共通か）
- 内部表現と出力構造の因果的対応の強さの比較
  （どちらの表現がより明示的に構造を符号化しているか）

#### Phase 4: 評価体系の構築

上記の分析を支える評価体系を確立する。

- 構造のレベル別の指標を設計する
  （トポロジー: 接続成分数、genus / 大域: プロポーション、部品配置 / 局所: 曲率分布）
- 既存指標（Chamfer distance, F-score）との関係を明らかにする
- 生成モデルの「構造的理解度」を定量化する指標を提案する

### 期待される成果

1. **「3D生成モデルは構造を理解しているか」に対する実験的な答え**
   - 内部状態と出力構造の因果的対応の有無と程度
   - 構造のどのレベルまで内部に表現されているか

2. **表現形式が構造認識に与える影響の記述**
   - sparse voxel と vectset で構造獲得のダイナミクスがどう異なるか
   - 構造的理解に有利な表現の条件

3. **3D生成モデルの構造的品質の評価体系**
   - 既存の全体的指標では捉えられない、レベル別の構造評価
   - 他の研究者が使える汎用的な評価ツール

### 会社の研究との関係

本研究は公開モデルの推論分析に限定され、モデルの学習・蒸留・
アーキテクチャ設計は一切行わない。成果は学術論文として公開される。
蒸留やアーキテクチャへの応用は、公開論文を参照する形で
別途行われるものであり、本研究の範囲外である。
