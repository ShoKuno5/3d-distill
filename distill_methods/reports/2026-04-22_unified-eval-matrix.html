Part 5 — Unified Evaluation Matrix (reference × alignment)

Previous: Part 4 (Cross-family Benchmark on Toys4k)
2026-04-22  |  Sho Kuno  |  Shanda AI Research Tokyo / The University of Tokyo
TL;DR. Prior reports (Parts 1–4) used different evaluation pipelines and different references (teacher mesh vs. ground-truth point cloud). This caused apparent ranking reversals that were hard to interpret. We re-evaluate the same 11 pre-existing checkpoints under a single unified pipeline, varying only two axes: (i) reference (Toys4k ground-truth pc10K.npz vs. teacher_50step predicted mesh) and (ii) alignment (24-start similarity ICP vs. identity). Training is not rerun — no checkpoint changes. The result is a 2×2 evaluation matrix that separates "how close to the real GT" from "how close to the teacher". Under this matrix, dmd2_exp2_plus_reg (DMD2 + regression hybrid) ties with teacher_50step on median CD vs. GT (Wilcoxon p = 0.54) and is the top non-teacher distilled method in both references.

1. Motivation

Across the previous 4 reports, different questions were asked under different pipelines:

  • Part 1 (2026-04-08) used eval_distill.py: reference = teacher_50step predicted mesh, no ICP alignment. Produced rankings like "DMD1 > DMD2 canonical" because DMD1's regression objective directly targets the teacher.
  • Part 4 (2026-04-21) used run_eval.py: reference = Toys4k pc10K.npz ground truth, with 24-start ICP alignment. Produced rankings like "DMD2 canonical ≳ DMD1" on median CD.

These are not contradictory — they measure different things. The goal here is to expose both axes explicitly and report all 2×2 combinations so that each method's behavior along reference and alignment can be read off directly. We also bring in every Hunyuan3D-2.1 distillation variant (including dmd2_exp2_plus_reg, which was never cross-family evaluated) and the TRELLIS family as cross-family context.

2. Experimental design

2.1 What varies across evaluations (two axes)

  • Reference source (2 values): gt = Toys4k pc10K.npz (10,000 GT surface points); teacher = teacher_50step predicted mesh for the same sample, cleaned and surface-sampled identically to predictions.
  • Alignment (2 values): With ICP = 24 cube-canonical initial rotations, similarity ICP with scale clamped to [0.5, 2.0]; No alignment = identity (only the per-cloud unit-sphere normalization shared by all methods).

2.2 What is held fixed (to isolate the above axes)

  • Test set: manifest_test.csv, 105 Toys4k samples (one per category). Identical across all methods.
  • Predictions: existing mesh outputs re-used without re-inference. No method is retrained.
  • Mesh cleaning: remove NaN/Inf/degenerate faces/unreferenced vertices; remove tiny components below 1% of largest component.
  • Surface sampling: 100,000 points for alignment, 16,384 for metrics (seed 0, area-proportional).
  • Normalization: unit-sphere fit, same for prediction and reference.
  • Metrics: Chamfer distance (L2 squared, bidirectional), Hausdorff distance, F-score @1% and @2%, bootstrap 95% CI over n=1000 resamples.
  • Statistical tests: paired Wilcoxon signed-rank test on per-sample Track A CD (same 105 object_ids across both models being compared).

6. Ablation: DMD2 Exp-3 (no GAN, no regression)

Catastrophic: all 105 test samples fail decoding.
Without a GT-bearing signal (GAN on real latents) or a teacher-bearing signal (regression against teacher pairs), the KL term alone — which operates on student-generated samples via the fake_score network — provides no stable learning target. The student converges to a latent distribution that is not decodable by the frozen volume decoder. This confirms that the GAN branch in canonical DMD2 is necessary, not cosmetic: it is the channel through which ground-truth-distribution information enters the student.

7. Interpretation

7.1 dmd2_exp2_plus_reg ties with teacher_50step on median CD vs. GT (Wilcoxon p = 0.54)

In Table A, the DMD2 hybrid ("Exp-2": GAN + regression) achieves median CD = 0.00226, slightly below teacher_50step's 0.00251. The paired Wilcoxon test on 105 samples gives p = 0.5362, well above any conventional significance threshold. The two methods are statistically indistinguishable on median CD vs. GT. This is a 1-step model matching a 50-step teacher.

7.2 flashvdm, teacher_50step, dmd2_exp2_plus_reg, cd_4step, dmd2_exp1_canonical cluster within ~30% of each other

Median CD vs. GT (Track A) for the top-5 H3D-2.1 methods: 0.00226, 0.00245, 0.00251, 0.00295, 0.00299. None of the pairwise differences within this cluster survive at p < 0.05. At N=105 we cannot resolve the distinction. The real signal is that 1-step distillation methods (Exp-1, Exp-2, flashvdm's 5-step turbo) match or exceed the 50-step teacher on median CD.

7.3 DMD1 vs. DMD2 canonical: tied under both references

DMD1 vs. DMD2 Exp-1 shows ns in both Table A (p = 0.15) and Table B (p = 0.91). The long-standing "DMD1 > DMD2" impression from Part 1 (2026-04-08) stemmed from unfixed DMD2 implementation bugs (replay buffer conditioning, mu_fake gradient path) and from Part 1's teacher-reference-no-ICP evaluation that favors DMD1's objective. Post bug fix (Part 2, 2026-04-14) and under unified evaluation, the median CD is not separable.

7.4 Regression + GAN dominates either alone in the small-data regime

In Table A vs. GT, Exp-2 (hybrid) statistically beats both DMD1 (p < 0.001) and Exp-1 (p = 0.039). In Table B vs. teacher, the same pattern holds (p = 0.0001 and p = 0.0159). With only 420 training samples, neither "teacher-pair regression alone" (DMD1) nor "GAN alone" (Exp-1 canonical) recovers the information that the hybrid captures. The original DMD2 paper discards regression; in this small-data regime that is a loss.

7.5 Frame-drift signature per method

The Track A vs. Track B gap (CD increase under identity alignment) quantifies how much ICP is recovering — effectively the student's frame drift relative to the reference:

  • Teacher_50step has the smallest Track B CD vs. GT, so its native frame is closest to the GT canonical frame.
  • dmd2_exp2_plus_reg has the largest Track A→B CD increase vs. GT. The hybrid's frame sits between teacher and GT canonical, so ICP helps it most against GT. (Against teacher, its Track B is competitive: it tracks teacher's frame well.)
  • dmd2_exp1_canonical has the largest Track A→B increase vs. teacher, consistent with having no teacher anchor in its loss (regression-free).
  • dmd1_k1 tracks the teacher frame tightly under both references (smallest drift vs. teacher) — a direct effect of its MSE-to-teacher-pairs objective.

7.6 Exp-3 failure is the empirical witness that GAN carries GT information

Removing the GAN branch from DMD2 — with regression also turned off — collapses the student entirely (all 105 samples fail). Since DMD1 succeeds with no GAN, the difference must be the information source: DMD1 uses teacher pairs; Exp-3 uses neither. The GAN's discriminator sees real GT-derived latents as "real" and provides an implicit GT-matching gradient to the student. In a data-free distillation regime this would be unavailable and the GAN branch inapplicable.

8. Caveats

  1. Single training seed per method. Each checkpoint is one training run. Variance across seeds — plausibly non-trivial for GAN-based methods (DMD2 variants) — is unquantified. A clean 3-seed replication is recommended before drawing strong conclusions about ≤10% differences.
  2. Train and test share the Toys4k distribution. DMD2's GAN explicitly trains against the training-set real-latent distribution. On a held-out split from the same distribution, this confers a "distribution prior" advantage relative to DMD1 (teacher-only). An out-of-distribution test (e.g. ShapeNet, GSO) would calibrate this advantage. This is not train/test leakage — the 105 test samples are disjoint from the 420 training samples — but it is an algorithmic information asymmetry.
  3. Reference-vs.-teacher eval is not fully symmetric. pc10K.npz is a 10k-point release cloud; teacher_50step is a 100k-point re-sample of the teacher's predicted mesh. The larger reference size makes ICP on the teacher reference ~10× slower but does not bias the relative model ordering.
  4. N = 105 with one sample per Toys4k category limits statistical power. Close comparisons (|Δmedian| < 3×10⁻⁴) cannot be resolved.
  5. cd_4step ties Exp-2 vs. teacher (Δmedian +1.3×10⁻⁵, p = 0.81) and nearly ties vs. GT (Δmedian +8.2×10⁻⁵, p = 0.15). At N=105, our unified evaluation cannot distinguish the two. Any claim of "best distilled method" is sensitive to the reference choice and should acknowledge this.
  6. flashvdm uses Hunyuan3D-2.0 weights, not 2.1. Its proximity to the teacher is partly a 2.0-vs-2.1 comparison rather than a pure distillation ablation. A fair v2.1 turbo VAE would require retraining.

9. Reproducibility

All predictions were generated in prior runs and re-used without modification. Only the evaluation pipeline was re-run.
